# Journal Style Adaptation

Use only after the target journal is known. Learn bounded language tendencies,
not research claims or a universal journal voice. Preserve the existing semantic
and author-authority gates. Never promise top-journal quality or acceptance.

## 1. Reuse Before Retrieval

Default shared directory: `D:\Codex\Academic Style Library`.
Use a user-specified shared directory instead when supplied. Keep one Markdown
file per journal, named from its verified full title with filesystem-invalid
characters replaced. Confirm identity from the file content, not its filename;
resolve ambiguous abbreviations with the author rather than guessing.

Read the matching profile, not unrelated projects. Check journal identity,
article type, covered sections, sample window, evidence locations, limitations,
and version. Infer article type from the supplied manuscript where unambiguous;
ask only if the distinction materially affects adaptation.

Reuse applicable rules without new retrieval. A changed article type, a material
rule conflict, an explicit refresh request, or evidence outside a requested
recent window calls for a bounded update. Apply only the matching portions;
do not mix a perspective's rhetoric into empirical Methods/Results.

Post-edit verification uses the profile version recorded for that edit, not
a newly updated profile. Do not silently change style targets mid-manuscript.

## 2. Retrieve And Screen Candidates

Use the registered `literature_rag` only for style-sample discovery. Check status
before first retrieval and inspect the live search schema. Use `index=global`
when available; do not send imaginary journal/year filters. Journal names,
dates, article types, and section names in queries are recall hints, not filters.
Do not modify the RAG, Zotero, indexes, source PDFs, or MCP configuration.

Default recency is five years back from the current editing date. Record the
actual window and publication-date basis. When only years are available, disclose
the fallback to five publication years (current year minus four through the
current partial year). If the author requires strict rolling dates, do not
substitute that fallback; exclude boundary-uncertain sources or ask for dates.
Exclude future publications and unverifiable dates from verified recent samples.

Start with 2-4 focused queries and seek roughly 3-5 distinct comparable papers.
If needed, make one bounded supplemental pass (normally at most two queries);
then report shortages rather than search indefinitely. An explicit broader
sample request may change this budget. Counts are a workload target, not proof
of representativeness or a reason to invent sample eligibility.

For each candidate:
- Verify journal identity and date from returned metadata or supplied records.
  Exclude or mark unknown when they cannot be verified; do not silently relax filters.
- Check article type and the relevant section from actual content. A generic
  `journalArticle` item type does not distinguish an experiment from a perspective.
- Deduplicate by verified bibliographic identity/DOI; multiple chunks are one paper.
- Prefer comparable articles from more than one author team when available.
- Record title, source/citation identifier, year/date, actual page/chunk locator,
  access scope, retrieval query, and inclusion/exclusion reason.

Do not claim exhaustive retrieval or whole-paper reading. Abstract-only evidence
supports abstract-level tendencies only. Verified section passages support only
their observed scope. Do not infer whole-paper sentence lengths, paragraph
lengths, citation densities, or section structure from scattered chunks.
If adequate text is missing, request supplied representative material when needed
or continue general editing; never automatically download papers or perform OCR.

## 3. Derive Bounded Rules

Organize observations by article type and section within the same file.
Focus on sentence information order, referents, concision, local transitions,
tense/voice, and calibrated claims. Preserve meaningful variation across authors.

Label each rule as `official requirement`, `sample observation`, or
`editorial suggestion`, and record confidence plus applicable scope.
Official requirements need a supplied or verified official source/date; published
examples alone do not establish them. Do not initiate web research solely to
fill that category unless requested or required for an explicit compliance claim.

A recurring sample observation needs support from at least two distinct papers;
otherwise label it a single-sample illustration, not a journal norm. Even 3-5
papers support only a provisional style reference, not statistical generalization.
Record counterexamples and uncertainty. Do not copy distinctive sentences,
import sample citations into the manuscript, or add scientific premises.

## 4. Single-File Profile And Saving

Use this compact layout, not additional manifests or databases:

    # <Verified Journal Name>
    ## Scope
    Identity/aliases; article types; covered sections; version/date; sample window
    and date basis; provisional/author-reviewed status.
    ## Editing Rules
    Rule ID | Type/section | Rule | Basis label | Sample IDs/locations | Confidence
    ## Sample Evidence
    Sample ID | Title/identifier | Date | Article type | Read scope/locator | Query
    Brief exclusion notes and minimal source excerpts only where needed.
    ## Limits And Updates
    Gaps, conflicting tendencies, pending official checks, dated change notes.

Create the directory/file only when there is evidence worth saving and saving is
allowed by the user's request. Ordinary journal-adapted saved editing may create
a new provisional profile; chat-only/no-save requests do not authorize shared
file writes. If saving is unavailable, keep a transient profile in the task and
disclose `not saved`; do not block general language editing.

Do not overwrite an existing confirmed profile silently. Propose substantive
updates for author confirmation, then update the same file with an incremented
version/date and concise history identifying superseded rules. Preserve any
old rule text still needed to explain a prior edit in that file's history.
For unconfirmed additions, keep them in the current task until approved.

Store only reusable style rules and sample provenance. Never store unpublished
manuscript text, author-specific results, private review letters, PDFs, or long
source extracts in the shared profile. Do not commit or upload the library
automatically. Record the exact profile version used in the project handoff.

## 5. Apply And Verify

Apply only rules supported for the current article type/section and consistent
with author preferences, verified official requirements, and protected meaning.
Scientific accuracy takes precedence over stylistic imitation. Route argument
reorganization or substantive compression to the section writer instead.

If RAG is unavailable, samples are insufficient, or a cached profile is unsuitable,
state the narrower scope and offer general academic editing. Do not fabricate a
profile or label generic editing as completed journal adaptation. An explicit
request requiring journal adaptation remains unmet until its evidence is available.
Keep the normal language verification gates; journal style status is separate.
